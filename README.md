# DsPH

This repository provides the MATLAB implementation of DsPH (Dual-similarity Preserving Hashing for Semi-Paired Cross-modal Retrieval).

## Running

The main entry point is `DsPH_demo.m`:

```matlab
result = DsPH_demo;
```

## Data
